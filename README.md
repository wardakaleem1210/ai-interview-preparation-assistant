# AI Interview Preparation Assistant

This folder contains a working prototype and the updated design package for the final-year project.

## Included files

- `app.py` — desktop prototype using Tkinter
- `question_bank.py` — interview question data and keywords
- `design_document.md` — updated requirements + system diagrams and flowcharts

## Run the app

```bash
cd interview_tool
python app.py
```

## Purpose

The project supports interview preparation by allowing users to:

- choose an interview category
- answer questions
- receive an automatic score
- view short feedback
- review a summary at the end of the session
